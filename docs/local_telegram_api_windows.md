# Локальный Telegram Bot API на Windows

Локальный Bot API снимает облачный лимит отправки файлов (до 2000 MB), но требует `api_id` и `api_hash` от [my.telegram.org](https://my.telegram.org/).

1. В `.env` проекта добавьте `TELEGRAM_API_ID=...` и `TELEGRAM_API_HASH=...`. Не отправляйте эти значения в чат и не добавляйте их в Git.
2. Запустите `scripts/run_local_telegram_api.ps1` в PowerShell из папки проекта и оставьте окно работающим.
3. После проверки сервера добавьте в `.env` проекта `TELEGRAM_LOCAL_API_URL=http://127.0.0.1:8082`, затем запускайте бота.
4. При первом переключении Telegram требует вызвать `logOut` для бота на облачном API. Это временно остановит его работу в облаке; переключение следует делать только после резервной копии и явного подтверждения владельца. После этого бот работает только пока включены компьютер, локальный сервер и интернет.

Сервер и его статистика привязаны к `127.0.0.1`; порты `8082` и `8083` не нужно открывать в роутере или публиковать в интернет. Файлы локального сервера сохраняются в `%LOCALAPPDATA%\InstagramBot\telegram-bot-api`.
