# Подключение пользовательского приложения

Первый интерфейс работает как Telegram Mini App и использует существующий сценарий скачивания бота. Сам веб-сервер запускается вместе с ботом; перед ним нужен HTTPS reverse proxy (например, Nginx/Caddy).

Добавьте в `.env` публичный адрес и локальный адрес прослушивания:

```dotenv
WEB_APP_URL=https://app.example.com
WEB_APP_HOST=127.0.0.1
WEB_APP_PORT=8081
```

Замените `app.example.com` на свой домен. Настройте HTTPS reverse proxy так, чтобы запросы к корню домена и путям `/assets/` и `/healthz` передавались на `http://127.0.0.1:8081`. Не публикуйте порт приложения напрямую в интернет.

После перезапуска бота в главном меню появится кнопка «Открыть приложение». Она доступна только при `WEB_APP_URL` с `https://`. В приложении пользователь вставляет ссылку; Telegram передаёт её боту, а готовый файл приходит в этот же чат.

Проверка сервера: `https://app.example.com/healthz` должна вернуть `{"status":"ok"}`. Пока домен и HTTPS не настроены, кнопка намеренно скрыта, а бот работает как прежде.

Это первая версия внутри Telegram. Для установки на главный экран и полноценной работы в обычном браузере потребуется отдельный этап: PWA-манифест, авторизация пользователя и веб-API.
